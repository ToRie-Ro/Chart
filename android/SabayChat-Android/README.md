# SabayChat Android

Native Android application scaffold for SabayChat built with Jetpack Compose.

## Structure

- app/
- core/
- designsystem/
- data/
- domain/
- features/

## Target

- Kotlin
- Jetpack Compose
- Modern Android devices

## Notes

This scaffold is designed to mirror the same backend and app behavior as the iOS app while preserving a clean Android architecture.
