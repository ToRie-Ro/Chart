# SabayChat iOS

Native iOS application scaffold for SabayChat built with SwiftUI.

## Structure

- App/
- Core/
- DesignSystem/
- Models/
- Services/
- Features/

## Target

- iOS 17+
- Swift 5.9+
- Xcode 15+

## Notes

This scaffold mirrors the required production app architecture and clean separation to match the SabayChat design system and backend.
